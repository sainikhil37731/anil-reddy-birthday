ANIL REDDY — 29TH BIRTHDAY WEBSITE
==================================

This ZIP contains the updated mobile-friendly website without background music.

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. For GitHub Pages, upload the CONTENTS of this folder to the repository root.
   Make sure index.html, style.css, script.js, and all three JPEG photos are directly at the repository root.

PROJECT STRUCTURE
- index.html
- style.css
- script.js
- anil-portrait.jpeg
- anil-pravallika-01.jpeg
- anil-pravallika-02.jpeg

FEATURES
- Cinematic black-and-gold birthday opening
- Responsive layouts for phones, tablets and desktops
- Three supplied photographs
- Tap-to-enlarge photo gallery
- Personal birthday letter from Pravallika
- Interactive birthday cake candles
- Golden confetti celebration
- No music or audio files

MOBILE TESTING
Use Chrome DevTools device emulation and test widths around 360px, 390px,
430px and 768px. Also test the deployed GitHub Pages URL on a real phone.
